# Aether Duo: 3D Online Co-op Adventure Game

یک بازی ماجراجویی سه‌بعدی آنلاین دونفره کاملاً هماهنگ و Co-op در بستر مرورگر با شخصیت‌ها، داستان، معماها و مکانیک‌های کاملاً اورجینال.

---

## ویژگی‌های اصلی

1. **اتصال دونفره آنلاین Real-Time**:
   - ساخت اتاق (Create Room) و تولید Room Code ۵ حرفی تمیز (مثلاً `AURA42`).
   - اشتراک‌گذاری سریع کد یا لینک مستقیم بازی (`?room=ROOM_CODE`).
   - اتصال بازیکن دوم و بررسی وضعیت اتصال به صورت زنده (Waiting -> Ready).
   - همگام‌سازی موقعیت (Position)، چرخش (Rotation) و انیمیشن‌ها (Idle, Run, Sprint, Jump, Ability) با فرکانس 45-60 FPS بدون لرزش (Interpolation).

2. **دو شخصیت کاملاً اورجینال**:
   - **Kaelen (The Spark Explorer)**:
     - سریع و چابک با کوله‌پشتی و عینک دید رادیویی.
     - توانایی **Spark Tether / Dash [F]**: پرتاب اشعه انرژی برای فعال‌کردن سوئیچ‌های دوردست و شارژ پدستال‌ها.
   - **Bram (The Stone Guardian)**:
     - قهرمان زره‌پوش سنگین با هسته انرژی باستانی.
     - توانایی **Aegis Barrier / Kinetic Bridge [F]**: ایجاد پل نوری جامد موقت یا انحراف لیزرهای دشمن، و برداشتن مکعب‌های مغناطیسی سنگین.

3. **سیستم معماهای نیازمند همکاری واقعی (Real Co-op)**:
   - **مرحله ۱: The Forgotten Garden (باغ فراموش‌شده)**:
     - صفحه فشار (Pressure Plate) که یک نفر روی آن می‌ایستد تا دروازه رونیک باز بماند، سپس نفر دوم اهرم دائمی را می‌کشد.
     - انتقال مکعب مغناطیسی سنگین توسط Guardian و شارژ آن توسط Explorer برای به حرکت درآوردن آسانسور قنات باستانی.
     - ایجاد پل نوری توسط Guardian روی پرتگاه و محکم‌کردن دائمی پل توسط اهرم Explorer.
   - **مرحله ۲: Floating Islands (جزایر معلق)**:
     - سکوهای متحرک بین جزایر هوایی تحت کنترل میل‌لنگ انرژی.
     - تورت نگهبان لیزری که پرتو آن توسط سپر Aegis مسدود شده و هم‌تیمی از پشت آن به هسته انرژی می‌رسد و آن را غیرفعال می‌کند.
     - گرداب باد ضدجاذبه به سمت پورتال قله.
   - **مرحله ۳: The Clockwork Factory (کارخانه مکانیکی)**:
     - گیر انداختن پیستون کوبنده با جعبه فولادی سنگین.
     - شیرهای بخار همزمان (Dual Timed Valves) که باید در عرض چند ثانیه با هم بچرخند.
     - دروازه باشکوه چرخ‌دنده‌ها و پیروزی Co-op.

4. **سیستم پینگ و ایموت (Ping & Emotes)**:
   - کلیدهای ۱ تا ۵ یا نوار ایموت: Wave 👋, Cheer 🎉, Point 👉, Heart 💖, Think 🤔 همراه با بالن سه‌بعدی بالای سر.
   - کلید `T` یا دکمه پینگ: ایجاد ستون نور سه‌بعدی و صدای رادار برای نشان دادن نقاط مهم به هم‌تیمی.

5. **پشتیبانی کامل موبایل و کامپیوتر**:
   - **کامپیوتر**: حرکت با WASD، چرخش دوربین با ماوس، پرش با Space، تعامل با E، اسپرینت با Shift، اسکیل با F.
   - **موبایل**: جوی‌استیک آنالوگ مجازی سمت چپ، کشیدن لمسی سمت راست برای چرخش دوربین، دکمه‌های پرش، تعامل و اسکیل.

## ساختار سرور و بدون نیاز به تنظیمات پیچیده

- سرور بازی با ترکیب **Express** و **WebSocket (`ws`)** روی پورت `3000` به صورت استاندارد کار می‌کند.
- تمام تبادلات و مدیریت اتاق‌ها به صورت داخلی روی بک‌اند انجام می‌شود و نیازی به API Keyهای گران‌قیمت یا سرویس‌های پولی جانبی نیست.

### نحوه اجرای پروژه:
```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور در حالت توسعه
npm run dev

# ساخت نسخه پروداکشن
npm run build

# اجرای نسخه پروداکشن
npm run start
```

### تست همزمان دو بازیکن در یک سیستم:
1. دکمه **Create Room** را بزنید تا اتاق ایجاد شود.
2. روی دکمه **Test 2nd Player in New Tab** کلیک کنید تا تب دوم باز شود.
3. در تب دوم دکمه **Connect to Game** را بزنید تا بازیکن دوم (Guardian) متصل شود.
4. بازی بلافاصله در هر دو پنجره همگام شده و حرکت، پرش و حل معماها به صورت Real-time بین دو پنجره منتقل می‌شود!
5. همچنین حالت **Solo Duo Sandbox** تعبیه شده است که با کلید `Tab` می‌توانید به تنهایی بین دو کاراکتر جابجا شوید و معماها را بررسی نمایید.
